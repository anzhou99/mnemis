P0
地基 · LLM 基础与工程规范
2–3 周 · 打好地基，避免后期返工
Prompt Engineering API 模式 项目架构
▶

核心学习内容

  • LLM 工作原理（Token、上下文窗口、温度）
  • System prompt 设计与 prompt 工程技巧
  • Anthropic / OpenAI API 深度使用
  • Python async/await、结构化输出（Pydantic）
  • 项目工程化：环境管理、日志、错误处理

实操目标

  • 搭建可复用的 LLM 调用基础库
  • CLI 对话机器人（含多轮上下文管理）
  • 结构化输出：让 LLM 返回可解析 JSON
  • 制定项目代码规范与 Git 工作流
📝 博客主题：从 API 调用到工程化 LLM 应用——我踩过的坑
P1
感知 · Tool Use 与 ReAct Agent
3–4 周 · Agent 的手脚：让 AI 能与世界交互
Tool Use Function Calling ReAct
▶

核心学习内容

  • Function Calling 原理与最佳实践
  • 工具设计：搜索、读文件、执行代码、调 API
  • ReAct 推理模式：Thought → Action → Observation
  • Agent 循环设计与终止条件控制
  • 工具结果的可靠解析与错误恢复

实操目标

  • 实现一个能调用网络搜索的研究助手
  • 支持读取本地文件、执行 Python 代码
  • 实现 ReAct 循环（附详细步骤日志）
  • 构建工具注册系统（可热插拔工具）
📝 博客主题：手把手实现 ReAct Agent——比 LangChain 更清晰的方式
P2
记忆 · RAG 知识库系统
3–4 周 · Agent 的大脑：检索增强，突破上下文限制
向量数据库 RAG Embedding
▶

核心学习内容

  • Embedding 原理与向量相似度搜索
  • Chunking 策略（固定、语义、递归分割）
  • 向量数据库实战：Qdrant / Chroma 对比
  • Hybrid Search：向量 + 关键词 BM25
  • Reranking、上下文压缩与引用溯源
  • 高级技术：HyDE、多步 RAG、GraphRAG 简介

实操目标

  • 构建个人知识库（支持 PDF、网页、笔记导入）
  • Agent 可自动检索知识库辅助回答
  • 实现答案带来源引用功能
  • 评估检索质量（Recall、MRR 指标）
📝 博客主题：RAG 不是银弹——深度剖析检索质量与幻觉问题
P3
持久 · Long-term Memory 系统
3–4 周 · Agent 的灵魂：跨会话记忆与自我认知
情景记忆 语义记忆 记忆管理
▶

核心学习内容

  • 记忆类型：情景（Episodic）、语义（Semantic）、程序（Procedural）
  • 记忆写入策略：何时写、写什么、怎么压缩
  • 记忆检索：相关性召回 vs. 时序优先
  • 记忆遗忘与更新机制（防止陈旧信息干扰）
  • 前沿：Mem0、MemGPT 架构解析

实操目标

  • 实现跨会话用户偏好记忆
  • Agent 能主动从历史对话提炼洞察
  • 记忆数据库设计（结构化 + 向量双存储）
  • 实现「记忆冲突」检测与合并
📝 博客主题：给 AI 一个长期记忆——设计一个不会忘记你的 Agent
P4
协作 · Multi-Agent 与 MCP 生态
4–5 周 · Agent 的团队：分工协作，处理复杂任务
Orchestrator Sub-agent MCP Human-in-loop
▶

核心学习内容

  • Multi-Agent 架构模式：Orchestrator-Worker、Peer-to-Peer
  • Agent 间通信：消息传递、共享状态设计
  • MCP 协议深度实践（工具服务器开发）
  • Human-in-the-loop：何时中断请求人工确认
  • 任务分解与并行执行（async 多 agent 协作）
  • 前沿：A2A 协议、Agent 网络概念

实操目标

  • 实现「研究员 + 写作者 + 校对员」三 Agent 协作
  • 开发自定义 MCP 工具服务器
  • Human-in-loop：关键决策节点插入人工审核
  • Agent 间传递结构化上下文（非裸文本）
📝 博客主题：Multi-Agent 系统实战——如何让多个 AI 真正协作而不是各说各话
P5
进化 · 自主规划与自我演进
3–4 周 · Agent 的野心：长视野计划与自我改进
长期规划 自我反思 自动优化
▶

核心学习内容

  • 长视野任务规划：目标分解、依赖图、里程碑
  • 自我反思（Self-reflection）：执行后评估与修正
  • 提示词自动优化（DSPy / 自动 prompt 调优）
  • Agent 行为评估框架设计（Eval 体系）
  • 前沿：Self-play、自主演进、Agent 自我更新

实操目标

  • Agent 能自动制定多步研究计划并执行
  • 实现执行后的自我评分与任务重试
  • 构建 Eval 测试集评估整体系统质量
  • Agent 能基于反馈改进自身行为
📝 博客主题：会自我进化的 Agent——从执行者到思考者的架构升级
P6
交付 · 全栈产品化与商业化
4–6 周 · 从原型到真实产品
全栈 UI 开源准备 变现路径
▶

核心学习内容

  • FastAPI + Next.js / React 全栈整合

  • 用户认证、数据隔离、API Key 管理
  • 成本控制：Token 预算、缓存、降级策略
  • 开源项目规范（README、Docs、贡献指南）

实操目标

  • 完整 Web UI：对话界面 + 知识库管理 + Agent 配置
  • 一键部署（Docker + Railway / Fly.io）
  • GitHub 开源发布（含完整文档）
  • 制定 SaaS 订阅 / API 变现方案
